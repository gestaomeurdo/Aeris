# AERIS Academy Command Portal

## 🚀 Cyber Space Interface v4.0.2
Este portal foi desenvolvido para cadetes de elite da **AERIS Academy**. A interface utiliza uma estética de comando tático com foco em alto desempenho e visual futurista.

### 🎨 Design System
- **Base:** Deep Blue Marinho (#020B1A)
- **Acento:** Ciano Neon (#00E5FF)
- **Estética:** Cyber HUD / Glassmorphism
- **Componentes:** Tactical Modules, Command Briefing e Neural Sync Status.

### 🛠 Tech Stack
- React + Vite
- Tailwind CSS
- Framer Motion (Animações de HUD)
- Lucide React (Ícones Táticos)
- Shadcn/ui (Base de Componentes)
